# 🐂🐻 불앤베어 꼬마투자단 (Bull & Bear)

가족이 함께 즐기는 주식 투자 보드게임 (디지털 앱).
초등학교 3학년 + 부모님 대상 금융 교육 게임.

**라이브 데모:** https://neal-md.github.io/bull-bear/

---

## 📖 게임 소개

스플렌더의 행동 선택 + 카탄의 섹터 연동 + 모두의마블의 보드 시각화를 녹인 가족용 투자 게임. 한 기기를 돌려가며 2~4명이 플레이하고, 한 판 25~40분.

### 핵심 컨셉
- **시장 예보 시스템**: 다음 라운드 사건이 미리 보여서 예측·전략적 매수 가능
- **6개 나라 시장**: 🇰🇷한국·🇺🇸미국·🇯🇵일본·🇨🇳중국·🇹🇼대만·🇮🇳인도 (실제 유명 회사 매핑)
- **6개 섹터**: 💻반도체·📱휴대폰·🚗자동차·🛒쇼핑·🏦은행·🎮게임
- **이벤트 2종**: 주가 이벤트(▲▼) + 배당 이벤트(증배/감배/중단)
- **비밀 목표 카드**: 각자 다른 목표 → 다양한 전략 유도

### 교육 목표
1. 싸게 사서 비싸게 팔기 (기본 원리)
2. **미래는 아무도 모른다** (가장 중요 — "무조건 오른다"는 말 경계)
3. 분산투자의 가치 (계란을 한 바구니에 X)
4. 위험 관리 (손절, 보험)
5. 배당 = 금융소득 (사과나무 비유)
6. 목표 설정과 시간의 힘

## 🚀 빠른 시작

### 그냥 게임만 하기
브라우저에서 `index.html` 열기. 끝.

또는 라이브 데모: https://neal-md.github.io/bull-bear/

### 수정·확장하기
1. `index.html` 한 파일에 게임 전체가 들어있음 (HTML/CSS/JS 통합)
2. 코드는 섹션별로 잘 구분돼 있음 (DATA / SETUP / TURN / RESOLVE / UI 등)
3. 수정 후 그냥 저장하고 브라우저 새로고침
4. 빌드 도구 없음, npm install 없음, 의존성 없음 (의도적인 단순함)

## 🎮 현재 버전: v7

### 주요 기능
- 6개 나라 시장 선택 (각 나라 고유 회사·성격)
- 난이도 프리셋 3종 (🌱초급/🌿표준/🌳고급) + 세부 옵션 5가지
- 한 라운드에 사건 2개 동시 발생 (총 26종 이벤트)
- 시장 예보 1~3 슬롯 (각 슬롯 2개 이벤트)
- 8종 대응 카드 (손절매·물타기·정보입수·보험·단타찬스·특별배당·이벤트뒤집기·긴급자금)
- 6종 비밀 목표 카드 (분산투자왕·테크신봉자·안전제일·현금부자·대박노리기·균형투자)
- 투자 도우미 (추천/비추천 + 이유 + 켜고끄기)
- 자동 게임 기록 (localStorage, 최대 50판)
- 교육 인사이트 자동 생성 (그 판 데이터 기반 맞춤 배울 점)
- ↩️ Undo (턴 되돌리기)
- 상장폐지 회사 예고 자동 정리
- 5,500원 멈춤(액면분할 없음, 단순화), 0원 상장폐지, 15주 보유 상한

### 기술 스택
- **순수 HTML/CSS/JavaScript** (프레임워크 없음)
- **localStorage** (게임 기록 보관)
- 빌드 도구·의존성 없음
