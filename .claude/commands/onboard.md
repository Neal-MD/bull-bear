불앤베어 꼬마투자단 프로젝트 온보딩. 아래 문서를 읽고 프로젝트를 파악한 뒤 요약해줘.

먼저 읽을 문서(내용이 아래에 첨부됨):
@README.md
@CLAUDE.md
@docs/DEV_HISTORY.md
@docs/DEV_NOTES.md
@docs/STOCK_MARKET.md

그리고 현재 작업 상태도 직접 확인해줘:
- `git log --oneline -5` (최근 작업)
- `git status` (커밋 안 된 변경)

읽고 나서 이 순서로 간단히 정리해줘:
1. **게임 개요** — 무엇을, 누구를 위해
2. **핵심 설계/밸런스 포인트** — DEV_NOTES 기준 중요한 결정들
3. **최근 작업 이력** — DEV_HISTORY + git log 기준
4. **지금 이어서 할 만한 것** — 자연스러운 다음 단계 제안

⚠️ 이 프로젝트는 자녀와 **아이패드 풀스크린**으로 함께 즐기기 위한 것이니, UI 변경 제안 시 항상 그 점을 고려할 것.
