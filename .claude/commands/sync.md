---
description: 원격(origin/main)과 동기화 — 최신 내용 받아오기
---

원격 저장소와 로컬을 동기화해줘.

1. `git fetch origin` 으로 최신 상태 가져오기
2. 로컬에 커밋 안 된 변경(`git status`)이 있으면 **먼저 보여주고**, 그대로 진행할지 물어봐 (덮어쓰지 말 것)
3. 깔끔하면 `git pull --rebase origin main`
4. 충돌이 나면 멈추고 어떤 파일이 충돌했는지 알려줘 — 임의로 해결하지 말 것
5. 결과 요약: 받아온 커밋 목록, 충돌 여부, 현재 로컬이 원격과 일치하는지
