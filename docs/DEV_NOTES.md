## 📌 현재 게임 사양 (최신 = 패치 3 적용본)

**개요:** 가족용 투자 보드게임. 스플렌더(행동 선택) + 카탄(섹터 연동) + 모두의마블(보드 시각화) 결합. 2~4인, 25~40분, 초3 이상.

**승리 조건:** 12라운드 후 순자산(현금 + 주식 평가액 + 목표 보너스) 최다.

**시작 자금:** 20,000원.

### 한 턴 행동 (2개 선택)
- A 매수 (같은 회사 한 턴 최대 3주) / B 매도 (제한 없음) / C 대응카드(사용 or 1장 뽑기) / D 패스(+**500원** ⬇)

### 라운드 마무리
예보 2장 중 좌측 실행 → 섹터 연동 → 예보 1칸 이동 + 새 카드 공개 → 배당 지급. **12R만 이벤트 비공개 후 실행.**

### 주가 트랙
500~5,500원. 0원=상장폐지, 5,500 초과=액면분할(주가 절반·주식 2배).

### 핵심 대응카드 (패치 3 반영)
손절매 / 물타기 / 정보입수(회사명만, 방향 가림) / 보험가입(매도 시 매입가 보장) / 단타찬스(행동+1) / 특별배당 / **이벤트 뒤집기(효과 반전)** ⬆ / **긴급자금(+3,000원 & 5주 허용)** ⬆

### 목표 카드 8종
분산투자왕(4개사, +5,000) / 모험가(우주 3주, +4,000) / 안전제일(배당주만) / 현금부자 / 대박노리기 / 균형투자 / 배당수집가 / **안정제일(무상폐, +2,000)**

## 📊 시뮬레이션 데이터 누적

### 시즌 1 (패치 1 / 개선 전 규칙) — 아빠 vs 큰딸
- **최종:** 큰딸 71,000 vs 아빠 61,350 → **큰딸 승** (점수차 9,650)
- **전개:** 딸이 우주·게임 공격투자, 마지막 라운드 우주 11주 올인으로 압승.
- **1위 역전:** 6회 (딸4·아빠2)
- **우주 최고가:** 4,500원
- **발견된 문제:**
  1. 🔴 막판 올인이 너무 강력 (확정정보 베팅)
  2. 🔴 정보입수 카드로 침체 예측해 압승 — 카드운=승부
  3. 🟡 분산투자(아빠) 끝까지 불리
  4. 🟡 우주 변동폭 과함
  5. (6R 발견) 보험 카드 평가방어가 너무 강하고 모호

### 시즌 2 (패치 2 / 개선 후 규칙) — 아빠 vs 큰딸
- **최종:** 큰딸 54,200 vs 아빠 50,650 → **큰딸 승** (점수차 3,550)
- **전개:** 접전. 딸이 게임 8주를 침체 직전 고점 매도로 현금화 + 우주 3주 회복해 모험가 목표(+4,000) 달성. 아빠는 분산 목표 한 끗 차이로 놓침(달성 시 55,650으로 역전승이었음).
- **1위 역전:** 7회
- **우주 최고가:** 3,500원
- **개선 검증 결과:**
  | 지표 | 시즌1 | 시즌2 | 평가 |
  |---|---|---|---|
  | 점수차 | 9,650 | 3,550 | ✅ 접전화 |
  | 우주 최고가 | 4,500 | 3,500 | ✅ 변동 완화 |
  | 막판 올인 | 가능 | 불가능 | ✅ 해결 |
  | 정보카드 위력 | 압승 요인 | 판단 필요 | ✅ 균형 |
  | 1위 역전 | 6회 | 7회 | ✅ 긴장 유지 |
- **남은 문제:**
  1. 🟡 빵집 거의 안 쓰임 (구색용 1~3주) → 패치 3에서 대응
  2. 🟡 대응카드 편차 (단타찬스·정보입수만 자주) → 패치 3에서 대응
  3. 🟡 패스(+1,000) 남용 경향 → 패치 3에서 대응

### 시즌 3 (패치 3 적용) — 아빠(안정파) vs 큰딸(공격파)
- **최종:** 아빠 77,000 vs 큰딸 67,500 → **아빠 승** (점수차 9,500)
- **설정:** 아빠가 작정하고 배당주(빵집·장난감) 집중, 딸은 우주·게임 공격. 패치 3 검증 목적.
- **전개:** 아빠 배당이 라운드당 1,800→7,200원까지 폭증. 후반 6라운드 배당만 약 4만 원 누적. 딸이 9R에 강화된 '긴급자금' 카드로 게임 11주 모아 49,500원 평가액으로 맹추격(격차 17,600→4,500), 그러나 아빠 배당 머신이 압도.
- **우주 최고가:** 3,000원 (변동 더 안정화)
- **가설 검증 결과:**
  1. 안정주 단독 전략 성립? → ✅ 성립 정도가 아니라 **압도적** (과함)
  2. 패스 500원으로 적극적 플레이? → ✅ 양쪽 다 적극 매수 (성공)
  3. 강화 카드 사용? → ✅ '긴급자금'이 딸 추격에 실제 사용됨 (성공)
  4. 전략 간 승률 균형? → ❌ 안정주가 너무 강해져 역균형 발생
- **🔴 핵심 발견 — 패치 3 과교정(over-correction):**
  - 배당 6,300~7,200원/라운드는 과함. 리스크 없이 후반 4만 원 수익.
  - 빵집 '불황 방어' + 고배당 겹쳐 안정주가 **저위험-고수익**(투자 기본원칙 위배).
  - 방향은 맞았으나 **강도가 과했음.** 조연 살리기는 성공, 무적화는 실패.

### 시즌 4 (패치 4 적용) — 진행 중

**규칙 명확화 (시즌 4 R7에서 발견·확정):** 빵집 '절반 방어'가 칸 단위와 충돌(−0.5칸 문제). → **해석 A 확정: 빵집은 −1칸 침체는 그냥 맞고, −2칸 이상 폭락일 때만 절반(−1칸)으로 방어.** "큰 위기에 강한 방어주" 성격. 패치 4에 통합.

**전반전(1~6R):** 딸(공격) 47,900 / 아빠(안정) 44,100, 격차 3,800.
- 성장주 보너스(+1칸 상승 시) 2회 발동: R3 우주 3,500 급등, R6 게임 3,500 급등 → 공격주 폭발력 부활.
- 배당 적정화: 라운드당 4,400원 (시즌3 6,300 대비 완화).
- 긴급자금 카드 재사용됨(딸 R6 게임 9주).
- 시즌3 동일 시점 아빠 +10,300 리드 → 시즌4 딸 +3,800 리드로 **균형 회복 뚜렷.**

**규칙 명확화 2 (시즌 4 R11에서 발견·확정):** 액면분할이 보유 상한(15주)과 충돌 + 초3에게 과도하게 복잡. → **액면분할 삭제. 주가는 5,500원에서 멈춤(상한선)으로 변경.** 상장폐지(0원=휴지) 위험 개념은 유지. 분할은 향후 고학년용 확장 모듈로 보류.

**후반전(7~12R):** R11 액면분할 삭제(5,500 멈춤) 적용 후 완주.
- **최종:** 큰딸 83,100 vs 아빠 52,650 → **딸 승** (점수차 30,450)
- 게임이 2,000→5,500 도달(9주, 마지막 49,500원 현금화가 결정타).
- 15주 상한 작동(아빠 적재 막힘), 빵집 막판 침체에 500원까지 하락(저위험-저수익 복원 확인).
- 🔴 **성장주 보너스(+1칸)가 과함:** 성장주 한 방으로 게임이 결정됨. 시즌1 막판올인과 유사한 결.

- **패치 5:** 성장주 보너스를 "+2칸 이상 상승 시에만 +1칸"으로 축소.

## 💻 디지털 앱 진화 이력

최종 확정된 규칙(시즌 2 균형 기반)을 코드로 구현한 뒤, 실제 플레이 피드백을 받아 단계적으로 기능 추가.

### 앱 v1 — 기본 구현
- 최종 규칙 전면 구현: 6개 회사, 우주 ±2칸·시작가 2,000, 배당 250/250, 15주 상한, 5,500 멈춤(분할 없음), 패스 +500, 매수 3주 제한, 12라운드, 최종 라운드 비공개.
- 한 기기 돌려가며 플레이(패스 스크린으로 비밀 목표 보호). 주가·배당·평가액·순자산 자동 계산. 대응카드 8종, 목표카드 6종 전부 구현.

### 앱 v2 — 플레이 피드백 반영 (사용자 직접 플레이 후)
1. **자산 현황 가시화** (피드백: "라운드마다 자산이 잘 안 보임")
   - 상단 미니 순위바(항상 표시, 현재 플레이어 강조)
   - 라운드 종료 시 상세 순위표 + 지난 라운드 대비 증감(▲▼) 표시
2. **사건 2개/라운드** (피드백: "예보 1개씩은 너무 단순")
   - 예보가 이번 2개 + 다음 2개 = 4개 정보. 경우의 수 대폭 증가.
   - 변동성 커짐 → 모니터링 필요(두 악재/호재 겹침 가능)

### 앱 v3 — 자동 기록 & 교육 인사이트
- **자동 저장**: 매 판 결과(날짜·순위·승자·인사이트)를 storage에 누적(최대 50판).
- **기록 보기 화면**: 누적 승수, 최근 게임 목록. 시작/결과 화면 양쪽에서 접근. 기록 삭제 기능.
- **교육 인사이트 자동 생성**: 그 판 실제 데이터 감지 → 맞춤 배울 점. 집중/분산 판정(maxConcentration), 배당왕, 상장폐지, 접전/대승, 목표달성, 그리고 항상 "미래는 모른다" 리마인더 + "배당도 변한다".

### 앱 v4 — 배당 이벤트 (피드백: "배당 증감도 반영되나?")
- 배당 이벤트 8종 추가: 증배(2배/1.5배), 감배(0.5배), 중단(0배). 주가는 불변, 그 라운드 배당만 변동(1라운드 적용).
- 예보·결과 화면에 배당 변동 별도 표시(노란 강조). 교육적으로 "주가와 배당은 별개" 학습.

### 앱 v5 — 투자 도우미 (추천/비추천) + 자료 내장
- **투자 도우미**: 예고 4개 분석 → 회사별 추천👍/주의👎를 *이유와 함께* 표시. 매수·매도 카드에 배지.
  - 설계 철학: 단순 화살표 X. ① 항상 "왜"를 함께 보여줌 ② 켜고/끄기(초보↔실전 모드) ③ "추천은 정답 아님" 반복 고지. → 교재 3장("무조건 오른다는 말 믿지 마라")과 충돌 방지, 추천 맹신 습관 예방.
- **앱 내 자료 열람**: 시작화면에 📖규칙/📚개념/💰돈이야기 버튼. 인쇄 자료의 요약본을 앱에서도 읽기.
- **보드게임 키트 → 규칙 설명서 전환**: 보드·카드 인쇄 요소 제거, 디지털 앱 기준 순수 규칙 설명서로 재작성.

### 앱 v6 — 난이도 프리셋 + 세부 옵션 (피드백: "처음엔 쉽게, 익숙해지면 어렵게")

## 🤖 시뮬레이션 #1 — 18,000판 자동 플레이 밸런스 분석 (2026-05-30)

> 도구: `sim/simulate.js` (index.html 순수 로직 포팅 + 5개 전략 AI). 3인 게임, 6국×3난이도 각 1,000판.
> 전략 5종(예보추종 forecaster / 몰빵 gambler / 분산 diversifier / 배당 dividend / 무작위 random)을 매 게임 3개 무작위 배정. 공정 승률 기준 = 33.3%. 원자료: `sim/results.md`.

### 핵심 발견
1. **🚨 교육 메시지 ↔ 최적 전략이 정반대 (최우선 이슈).**
   - 승률: **몰빵 61.2%** > 예보추종 47.6% > 배당 32.0% > **분산 20.5%** > 무작위 4.7%.
   - 게임은 "계란을 한 바구니에 담지 마라(분산투자)"를 가르치는데, **기계적으로는 한 종목 몰빵이 압도적 최선이고 분산이 거의 최악.** 결과 인사이트에서 분산을 칭찬하지만 플레이로는 몰빵이 학습됨 → 메시지 모순.
   - 근본 원인: **예보가 100% 정확한 신탁(oracle)** 이라, 오를 종목을 미리 알고 몰빵하면 위험이 없음. 분산은 손해. (random 4.7% = 운 게임은 아님, 실력이 지배적 → 그건 좋음.)
   - 개선 방향(택1/혼합): ① 예보 신뢰도 낮추기(가끔 빗나감 / 방향 숨기고 회사만 공개) ② 집중 보유에 비용·세금·상한 ③ 분산 보상 강화(분산 보너스를 1인 비밀목표가 아닌 공통 규칙으로). **밸런스 수정과 교육 효과가 같은 방향.**

2. **🐞 B1 확정** — 비밀목표 `모험가` 0.0%, `안전 제일` 0.0% 달성 (8,900여 회 등장 전부 실패). 나머지 목표는 44.6~55.4%. 죽은 코드 확정, 현재 섹터로 재정의 필요.

3. **상장폐지가 너무 잦음** — 게임당 1개 회사가 0원이 되는 비율: 인도 95.0% · 중국 89.5% · 대만 78.4% · 한국 77.0% · 일본 57.4% · 미국 31.6%. 한 판에 회사 하나가 망하는 게 "기억에 남는 사건"이 아니라 거의 매판 일어나는 노이즈. 특히 중국·인도는 과함. (반면 나라별 위험 서열은 의도대로 작동 → 설계 방향은 옳음.)

4. **압승이 너무 잦고 접전이 드묾** — 1·꼴찌 격차 ≥2만원 비율: 초급 60.8% / 표준 56.3% / 고급 31.0%. 접전(≤5천) 비율은 초·표준 ~5%뿐. **절반 이상의 판이 한 명이 크게 앞서는 일방적 게임** → 가족(특히 9세)과 할 때 긴장감·재미 저하 우려. 고급이 그나마 접전(8.9%). 캐치업/스노우볼 완화 검토.

5. **고급 난이도에서 배당(금융소득) 거의 소멸** — 인당 배당 표준 18,455원 → 고급 5,940원 (divEvery=3). 시작자금도 적어 전체 자산도 절반(31k vs 48~53k). "배당=금융소득" 핵심 교훈이 고급에선 거의 안 와닿음.

6. **위험국에서 원금 손실 플레이어 비율 높음** — 게임 종료 시 시작자금 미만으로 끝난 비율: 인도 16.7~18.7%, 중국 13~16% vs 한국·미국·일본 1~8%. 아이가 "돈을 잃고 끝나는" 경험이 위험국에선 1/6 꼴 → 좌절 가능. 나라 위험 안내와 연결하거나 완화.

### 검증된 것(설계가 잘 된 부분)
- 나라 성격(volMod/divMod/startMod)이 부·위험 서열로 정확히 반영됨: 미국=가장 안전·부유, 인도=가장 위험·빈곤.
- 실력이 운을 이김(무작위 4.7%). 예보 읽기·타이밍이 분명히 보상됨.

### AI 한계(주의)
- 전략 AI는 카드(손절/물타기/보험/정보)를 단순 휴리스틱으로만 사용. 몰빵 AI는 예보 신탁을 완벽히 front-run → 인간보다 약간 더 최적. 다만 "예보 보고 몰빵하면 이긴다"는 결론은 아이도 곧 학습할 실제 경향이라 유효.
