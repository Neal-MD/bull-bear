# 골드 볼트 은행 테마 전면 리디자인 — 설계

> 날짜: 2026-06-07 · 작업자: 송창환(+따님) + Claude
> 트리거: 사용자 요청 "디자인을 마치 은행에 온 것처럼 만들어줘" → 비주얼 컴패니언으로 방향 확정.
> 관련 기억: [[bull-bear-design-direction]]. 이전 부루마블/카탄 보드게임 컨셉을 **골드 볼트 은행 테마**로 피벗.

---

## 1. 목표 / 범위

`index.html` 단일 파일 게임의 **비주얼을 전면 "은행 테마"로 리스킨**한다. 따님이 후보 3개(골드 볼트 / 민트 저금통 / 지폐 장부) 중 **A. 골드 볼트**(에메랄드 그린 + 금색)를 선택. 6대 시그니처 요소 전부 채택.

**범위 안:** CSS 팔레트·컴포넌트 스타일, 일부 렌더 함수의 마크업/클래스 추가, 탭/연출 애니메이션, 인앱 텍스트의 은행 용어 살짝.

**범위 밖(절대 불변):**
- 게임 로직·확률·밸런스(방금 끝낸 상폐/시작가/시작자금 변경 포함) — 건드리지 않음.
- `sim/*` — 시뮬은 렌더가 없으므로 무관, 수정 없음.
- 외부 라이브러리·빌드 단계·localStorage 외 저장소 — 도입 금지(CLAUDE.md).
- 단일 HTML 파일 구조.

## 2. 제약 (반드시 준수)

- 아이패드 세로(약 820×1180) 우선. 스크롤 최소.
- 초3 친화: 텍스트 쉬움, 한 줄에 의미 전달, 색으로 구분.
- **한국 증시 색 유지**: 오름=빨강 ▲, 내림=파랑 ▼. 은행 베이스(녹/금)와 충돌하지 않게 배지로 분리.
- 색약 안전: 색 + 화살표(▲▼) + 부호(+/−) 병행.
- 모션은 transform/opacity만(60fps), `prefers-reduced-motion: reduce` 존중(연출 축소/생략).
- 동전·연출이 클릭 응답성을 막지 않게(연출은 비차단, pointer-events 주의).

## 3. 디자인 토큰 (팔레트)

`:root` CSS 변수를 골드 볼트로 재정의. 기존 변수명 최대한 재사용해 영향 범위 최소화.

| 토큰 | 값(개념) | 용도 |
|---|---|---|
| `--bg` | 아이보리 크림(밝게 유지) | 본문 배경(가독성) |
| `--vault` | 깊은 에메랄드 `oklch(~0.30 0.06 165)` | 헤더·금고문·강조 패널 |
| `--vault-deep` | 더 어두운 그린 `~0.22 0.05 165` | 그림자/테두리 |
| `--gold` / `--gold-deep` | 금색/짙은 금 | 브랜드·테두리·CTA |
| `--brass` | 놋쇠 `~0.72 0.10 85` | 명패·라인 |
| `--led-bg` | 근검정 `~0.18 0.02 160` | 전광판 배경 |
| `--up`(빨강) / `--down`(파랑) | 그대로 | 증시 색(불변) |
| `--paper` | 통장 종이 크림 | 결산 통장 |

본문은 **밝게** 유지(아이 가독성). 어두운 면은 헤더·금고문·전광판 등 포인트에만.

## 4. 6대 요소 → 구현 매핑

각 요소는 기존 화면/함수에 얹는다. 함수 구조(렌더 흐름)는 유지.

1. **🔐 금고문 시작 화면** — 최초 진입 시 금고문 스플래시 오버레이(타이틀+다이얼). "게임 시작/입장" 탭 → 다이얼 회전 + 문 양옆/회전 열림(@keyframes, ~0.8s) → `renderSetup()`. 탭으로 즉시 스킵 가능. reduced-motion이면 페이드만.
   - 구현: 새 `vaultIntroHTML()` + `openVault()` 오버레이. 게임 로직 진입점(`renderSetup`/`startGame`)은 그대로 호출.
2. **🪟 창구 헤더** — `.topbar`를 은행 창구 카운터로 리스킨(에메랄드 바 + 놋쇠 명패에 현재 플레이어·잔액, 골드 트림). 마크업 거의 유지, CSS 위주 + 명패용 클래스 약간.
3. **📟 LED 시세 전광판** — `.fcreel`/`.fcrow`/`.mini-ev`를 LED 보드로 리스킨(근검정 패널 + 발광 글자, 골드/빨강/파랑 glow). **`fcReelHTML()` 로직·구조 유지**, CSS + 클래스만. 안개(❓)·배당 칩 그대로.
4. **📔 통장 결산** — 라운드 결과/순위(`showEventReveal`/결과 화면)를 통장 거래명세로 리스킨(장부 가로줄, 입금 ▲/출금 ▼/배당 행). 데이터·계산 불변, 표현만.
5. **🪙 동전·배당 효과** — 현금 표기에 🪙, 자산 타일에 금고 질감. **배당 지급·매수 시 동전 버스트** 연출(CSS 파티클, 비차단). 결산 배당 행 강조.
6. **🧑‍💼 은행원 마스코트** — 기존 🐂🐻 유지 + 은행원 터치(모자/넥타이 이모지 조합 또는 작은 CSS 배지). 정체성 유지.

## 5. "누르면 팡 터지는" 연출 (사용자 강조 요청)

impeccable(animate/delight/overdrive)로 **juicy 탭 피드백**을 넓게 적용:
- 모든 주요 버튼: 프레스 시 눌림(scale/translateY) + 골드 광택 스윕 + 탭 릴리스 팝.
- 매수(＋): 타일에서 **금화 튐**(coin pop) + 숫자 카운트업 느낌.
- 배당/패스 보상: **동전 쨍그랑** 버스트 + 잔액 명패 반짝.
- 카드 사용: 카드가 떠오르며 빛나는 효과.
- 라운드 결산: 통장에 줄이 **타닥 찍히는** stagger, 순위 변동 ▲▼ 팝.
- LED 전광판: 이번 칸 점멸(● 지금) + 샤인 스윕(기존 v8 모션 계승).
- 전부 transform/opacity, reduced-motion 존중, 색약 안전.

## 6. 구현 순서 (계획 단계에서 세분화)

1. 토큰/팔레트 교체 + 전역 배경/버튼 베이스 → 헤드리스 스냅샷으로 회귀 확인.
2. 창구 헤더 → LED 전광판 → 금고 자산 타일(매 턴 보이는 핵심부터).
3. 금고문 시작 화면(오버레이+애니메이션).
4. 통장 결산 + 동전 연출.
5. 마스코트 터치 + 전역 juicy 탭 피드백 패스(impeccable).
6. 인앱 문구 은행 용어 소폭(과하지 않게), DOCS 일관성.

## 7. 검증

- JS 문법 검사(스크립트 블록 `new Function`).
- 헤드리스 820×1180 스크린샷: 금고문 / 셋업 / 플레이(전광판·타일) / 통장 결산 / reduced-motion.
- 실제 한 판 끝까지 플레이(아이패드 폭) — 레이아웃 깨짐·스크롤 과다·탭 응답성 확인.
- 게임 로직 불변 확인(밸런스 수치·상폐 규칙 그대로).

## 8. 위험 / 트레이드오프

- **CSS 표면이 넓어 레이아웃 회귀 위험** → 토큰 교체 후 즉시 스냅샷, 단계별 확인.
- **금고문 인트로가 매번이면 성가심** → 빠르게(~0.8s)+탭 스킵+진입 1회. reduced-motion이면 생략.
- **어두운 전광판 vs 밝은 본문 대비** → 본문은 밝게 유지, 어두움은 포인트에만. 전광판 글자 충분히 크게(9살 가독).
- **연출 과다 → 산만/성능** → 비차단·짧게·reduced-motion 존중. 핵심(매수·배당·결산)에 집중.
- 단일 파일이라 CSS가 길어짐 — 섹션 주석으로 가독성 유지.

## 10. 추가 기능 (사용자 요청 2026-06-07, 디자인과 함께 구현)

비주얼이 아닌 **기능** 추가. 밸런스 영향 없음(재시뮬 불필요).

### 10-1. 지난 라운드 결과 다시 보기
- **문제:** pass-and-play 특성상 라운드 결산(`showEventReveal`)은 **마지막 턴 플레이어만** 보고 다음 라운드로 넘김 → 나머지는 못 봄.
- **해결:** 결산 데이터는 이미 `G.lastChanges`에 저장됨. `showEventReveal(review=true)` 리뷰 모드 추가 — 하단 버튼을 "다음 라운드로/최종결과" 대신 **"닫기(원래 화면 복귀)"**로. 복귀 대상은 현재 `G.phase`('pass'→`showPassScreen()`, 'turn'→`render()`).
- **버튼 위치:** 패스 화면에 **"📔 지난 라운드 결과"**(다음 차례 사람이 시작 전 확인). 턴 화면 헤더에도 작게 둘지는 공간 보며 결정. **1라운드(첫 결산 전, `G.lastChanges.changes` 없음)엔 숨김.**
- 은행 테마의 **통장 결산** 화면을 그대로 재사용.

### 10-2. 시작 순서 무작위
- **문제:** 항상 입력 순서대로(아빠가 늘 먼저).
- **해결:** `startGame`에서 플레이어 배열을 `shuffle`해 차례 무작위화(각 플레이어의 이름·아바타·목표는 그대로 따라감). 첫 패스 화면(또는 1라운드 진입)에 **"이번 순서: A → B → C (무작위로 정했어요)"** 안내 1회.
- 밸런스 무관(시뮬은 이미 전략 무작위 배정). 재시뮬 불필요.

## 9. 완료 정의

골드 볼트 은행 테마로 전 화면 리스킨 + 6요소 + juicy 탭 연출 적용, 아이패드 세로에서 한 판 완주 가능, 게임 로직/밸런스/시뮬 불변, 문법·스냅샷 검증 통과, DOCS 일관성 유지.
