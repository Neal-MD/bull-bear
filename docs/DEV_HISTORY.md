# 🛠️ 개발 이력 (DEV_HISTORY)

> **게임명:** 불앤베어 꼬마투자단 (Bull & Bear)
> 황소(상승장)/곰(하락장) 상징을 이름에 담은 가족용 금융 교육 게임.
>
> 이 문서는 게임 설계의 모든 결정·시뮬레이션 데이터·밸런스 변경 이력을 누적 기록합니다.
> 새 작업 시 이 문서를 먼저 읽고 컨텍스트를 파악하세요.

## 📌 현재 사양 (v7 기준)

### 게임 개요
- 2~4인, 25~40분, 12라운드, 한 기기 돌려가며 플레이
- 6개 나라 시장 선택 (각 나라 6개 회사)
- 시작 자금: 2만원 (난이도에 따라 1.5만~2.5만)
- 승리: 순자산(현금 + 주식 평가액 + 목표 보너스) 최다

### 6개 섹터
| 섹터 | 아이콘 | 타입 | 기본 시작가 | 기본 배당 |
|---|---|---|---|---|
| tech | 💻 | growth | 2000 | 100 |
| phone | 📱 | mid | 1500 | 150 |
| auto | 🚗 | mid | 1500 | 150 |
| shop | 🛒 | divid | 1000 | 250 |
| bank | 🏦 | divid | 1000 | 250 |
| game | 🎮 | growth | 2000 | 100 |

### 6개 나라
| 나라 | 변동 보정 | 배당 보정 | 시작가 보정 | 성격 |
|---|---|---|---|---|
| 🇰🇷 한국 | 0 | 0 | 0 | 표준 |
| 🇺🇸 미국 | -1 | +50 | +500 | 안전·배당 좋음 |
| 🇯🇵 일본 | -1 | +30 | +200 | 가장 안전 |
| 🇨🇳 중국 | +1 | 0 | -200 | 출렁임 |
| 🇹🇼 대만 | 0 | 0 | 0 | 표준 (칩 비중 큼) |
| 🇮🇳 인도 | +1 | -30 | -500 | 싸지만 성장형 |

### 핵심 규칙
- **턴**: 행동 2개 (매수/매도/카드/패스)
- **매수 제한**: 같은 회사 한 턴 3주 (난이도별 2~5)
- **예보**: 1~3 슬롯 × 사건 2개 (난이도별)
- **주가**: 0원=상장폐지, 5,500원=멈춤(액면분할 없음)
- **보유 상한**: 한 회사 15주
- **배당**: 매라운드 (난이도에 따라 2R/3R마다)
- **패스 보상**: +500원
- **최종 12라운드 예보 비공개**: 막판 올인 방지

## 📊 시뮬레이션 데이터 (시즌 1~5)

가상의 가족(아빠 vs 큰딸) 12라운드 대결로 밸런스 검증.

### 시즌 종합 비교
| 지표 | 시즌1 | 시즌2 ⭐ | 시즌3 | 시즌4 | 시즌5 |
|---|---|---|---|---|---|
| 승자 | 딸(공격) | 딸(공격) | 아빠(안정) | 딸(공격) | 딸(공격) |
| 점수차 | 9,650 | **3,550** | 9,500 | 30,450 | ~30,600 |
| 우주 최고가 | 4,500 | 3,500 | 3,000 | 5,500 | 5,500 |
| 승부처 | 막판 올인 | 목표+현금화 | 배당 누적 | 성장주 폭발 | 성장주 폭발 |
| 1위 역전 | 6회 | 7회 | - | - | - |

### 핵심 발견
**시즌 2가 압도적 최적 균형** (점수차 3,550). 다른 모든 시즌은 9,500~30,600으로 한쪽이 크게 우세.

밸런스의 핵심 축은 **"성장주의 폭발력을 얼마나 허용하는가"**:
- 너무 약하면 → 안정주 무적 (시즌3)
- 너무 강하면 → 성장주 한 방 게임 (시즌1·4·5)
- **시즌2 지점이 균형** (성장주 보너스 없음, 우주 ±2칸, 안정주 배당 200)

→ 최종 확정 버전(v5/v7 기반)이 시즌2 규칙을 채택.

## 💻 디지털 앱 진화 (v1 → v7)

### v1 — 기본 구현 (최종 확정 규칙 코드화)
시즌1~5 시뮬레이션을 거쳐 확정된 규칙을 그대로 구현. 6개 회사(아이스크림·장난감·게임·빵집·반려동물·우주탐험), 12라운드, 자동 계산, pass-and-play.

### v2 — 자산 가시화 + 사건 2개/라운드 (실제 플레이 피드백)
- 상단 미니 순위바 + 라운드 종료 시 상세 순위표(증감 표시)
- 예보가 [이번 2개 + 다음 2개]로 진화

### v3 — 자동 기록 + 교육 인사이트
- localStorage에 매 판 결과 저장 (최대 50판)
- `generateInsights()`: 그 판 실제 데이터 감지해 맞춤 메시지 생성
- "지난 게임 기록" 화면 추가

### v4 — 배당 이벤트 추가
- 배당 이벤트 8종 (증배 2배/1.5배, 감배 0.5배, 중단 0배)
- 주가는 그대로, 배당만 변동 (1라운드 적용)
- "주가와 배당은 별개" 학습

### v5 — 투자 도우미 + 인앱 자료 열람
- `analyzeAdvice()`: 예고 분석해 회사별 추천👍/주의👎 + **이유** 표시
- 토글 가능 (초보/실전 모드)
- 시작 화면에 📖규칙/📚개념/💰돈이야기 버튼 (인쇄 자료 요약본)

### v6 — 난이도 프리셋 + 세부 옵션
- 프리셋 3종 (🌱초급/🌿표준/🌳고급)
- 세부 옵션 5가지 (매수 제한·예보 길이·배당 주기·시작 자금·도우미 시작상태)

### v7 — 나라 시장 + Undo + 상폐 예고 정리 (현재)
- 🌍 6개 나라 선택 (한국·미국·일본·중국·대만·인도)
  - 각 나라 6개 섹터에 실제 유명 회사 매핑
  - 나라별 성격: 변동성·배당·시작가 보정
  - 이벤트는 섹터 슬롯 기준 추상화 (공통 풀)
- ↩️ Undo: 턴 시작 시점 스냅샷 복원
- 상장폐지 회사 영향 카드는 예보에서 자동 제거·재충전

## 🚧 알려진 한계 & 향후 모니터링

1. **사건 2개/라운드 변동성**: 두 악재 겹치면 큰 폭락 가능. 초3이 따라오는지 관찰.
2. **화면 정보량**: 도우미 켜면 정보가 많음. 아이패드에서 답답하지 않은지 확인.
3. **나라별 차별화**: 현재는 수치 보정만. 더 강한 차별화(나라 고유 이벤트) 검토 가능.
4. **localStorage 한계**: 기기/브라우저 바뀌면 기록 유실. 클라우드 동기화 없음(의도).
5. **공유 데이터베이스 없음**: 가족끼리 별도 기기로 플레이하면 기록이 합쳐지지 않음.

## 🎯 설계 결정 근거 모음

작업 시 "왜 이렇게 했지?" 헷갈리는 부분의 답:

### 왜 액면분할을 뺐나?
v5 시뮬레이션에서 보유 상한(15주)과 충돌(9주→18주는 상한 초과). 초3에게 개념도 어려움. → 5,500원 멈춤으로 단순화. 고학년용 확장 모듈로 보류.

### 왜 빵집 불황 방어를 뺐나?
v4(과교정 시즌)에서 빵집이 "저위험-고수익" 무적이 됐음. 위험-보상 균형 원칙 위배. → 삭제하고 배당으로만 차별화.

### 왜 성장주 보너스를 뺐나?
v6 시즌5에서 미세 조정해도 게임 폭등 호재가 다 +2칸 이상이라 효과 없음. 성장주 한 방 게임을 막을 수 없었음. → 메커니즘 자체 삭제.

### 왜 투자 도우미는 "이유"와 "토글"이 함께 있나?
- 단순 화살표만 보여주면 "왜?"를 안 배움 → 이유 같이 표시
- 익숙해진 뒤에도 도우미가 켜져 있으면 의존성 생김 → 토글로 보조바퀴 뗄 수 있게
- "추천 맹신" = 어른 투자 사기의 가장 큰 원인. 교재 3장과 일관성 유지

### 왜 마지막 라운드 예보를 비공개로?
v2(시즌1) 가족의 우주 11주 올인이 게임 결정. 확정 정보 베팅은 "예측"이 아니라 "확실한 베팅". 교육적 가치 X.

### 왜 한 기기 돌려가며 플레이인가?
- 가족이 가까이 모이는 경험 자체가 목적
- 멀티 디바이스 동기화는 백엔드 필요 → 의도적 단순함
- pass 스크린으로 비밀 목표는 보호됨
