## 🐞 버그 / 동작 안 함 (우선순위 높음)

### B1. 비밀목표 6개 중 2개가 달성 불가능 (죽은 코드)
- `GOALS` 배열에서:
  - **🚀 모험가** — `p.shares.space>=3` 를 검사하는데 `space`(우주탐험)라는 주식이 없음. 현재 섹터는 `tech/phone/auto/shop/bank/game`.
  - **🛡️ 안전 제일** — `toy`(장난감)·`bakery`(빵집)만 보유 시 달성인데 두 섹터 모두 존재하지 않음.
- 옛 버전(다른 섹터 구성)의 잔재로 보임. **현재 섹터 체계로 목표 조건을 다시 정의해야 함.**
- 영향: 이 두 목표를 받은 플레이어는 보너스를 절대 못 받음 → 불공정.

### B2. 게임 기록 저장/불러오기가 실제로 동작하지 않음
- `saveGameRecord` / `showHistory` / `clearHistory` 가 `window.storage.get/set/delete` 를 사용.
- `window.storage` 는 일반 브라우저(아이패드 사파리·GitHub Pages)에 **존재하지 않는 API** → 모든 호출이 예외 → 기록이 항상 빈 상태.
- 영향: "지난 게임 기록 보기" 기능이 사실상 죽어 있음. **`localStorage` 기반으로 교체 필요.**
- 비고: 아이패드로 반복 플레이하는 사용 시나리오에서 누적 전적/통계가 핵심 재미 요소가 될 수 있어 우선 처리 권장.
