# 🎨 보드게임 리디자인 — 디자인 브리프

> 작성 2026-05-30 · 컨텍스트 `/.impeccable.md` · 대상 `index.html` (단일 자체완결, 외부의존성 0 유지)
> 방향 확정: **부루마블 스타일(밝고 알록달록)** · 무스크롤 한 화면 · 중복버튼 정리 · 화려한 효과

## 1. Feature Summary
부모+9세 자녀가 아이패드 풀스크린으로 함께하는 가족 투자 보드게임. 현재의 "다크 주식앱" UI를 **밝은 부루마블식 보드게임**으로 바꾼다. 인게임 턴 화면이 **스크롤 없이 한 화면**에 들어오고, 중복 버튼을 통합하며, 매 행동에 **화려한 즉각 연출**을 준다.

## 2. Primary User Action
내 차례에 **보드 타일(6개 섹터)을 보고 ＋(사기)／－(팔기)** 하는 것. 이 한 동작이 화면의 주인공.

## 3. Design Direction
밝고 따뜻한 보드판 위에 알록달록 나라/섹터 타일. 가격은 동전·지폐 토큰처럼, 큰 숫자. 황소🐂(상승)/곰🐻(하락) 마스코트가 화면 모서리에서 반응. 안티: 다크 주식앱·기업톤·무채색. (원칙: `.impeccable.md` 5개 — 화면은 보드판 / 큰 손가락·큰 숫자 / 행동엔 보상 / 한 번에 하나 / 색으로 의미.)

## 4. Layout Strategy — 무스크롤 한 화면 (인게임 턴)
풀스크린 고정 레이아웃(세로 flex, body 스크롤 없음). 아이패드 전체 폭 사용(기존 max-width:900 중앙정렬 제거 → 가로 공간 활용).

```
┌──────────────────────────────────────────────┐
│ [슬림 톱바] 🎲3/12  🇰🇷한국   👧지민 💰25,000  🥇🥈🥉  🎯 🟢 │  ← 랭킹을 톱바에 흡수
├──────────────────────────────────────────────┤
│ [예보 스트립] 이번 칸 사건 ▸ 🤖반도체▲  📉경기▼   다음▸❓ │  ← 슬림
├──────────────────────────────────────────────┤
│                  ★ 보드 (주인공) ★              │
│   ┌──────┐ ┌──────┐ ┌──────┐                  │
│   │ 💻    │ │ 📱    │ │ 🚗    │   6개 섹터 타일   │
│   │삼성2,000││SKT1,500││현대900 │   = 시세 + 거래   │
│   │▲200 보유2││  ▼100  ││  -    │   합친 보드       │
│   │ －  ＋ │ │ －  ＋ │ │ －  ＋ │  ← 타일에 ＋/－   │
│   └──────┘ └──────┘ └──────┘                  │
│   ┌──────┐ ┌──────┐ ┌──────┐                  │
│   │ 🛒    │ │ 🏦    │ │ 🎮    │                  │
│   └──────┘ └──────┘ └──────┘                  │
├──────────────────────────────────────────────┤
│ [하단 액션바] 남은행동 ●● │ 🃏카드 │ 💰패스 │ ↩️ │ ✅턴종료 │
└──────────────────────────────────────────────┘
🐂(좌하)         🐻(우하)  ← 마스코트, 이벤트에 반응
```

**중복 제거(확정):**
1. **시세 카드 + 거래 카드 → 보드 타일 하나로 통합** (6주식을 두 번 그리던 것을 한 번). 타일이 곧 시세이자 거래.
2. **미니 랭킹 줄 → 톱바로 흡수**.
3. 패스/되돌리기/턴종료/카드 = 하단 액션바에 1세트만.
4. "카드 뽑기" 타일 → 🃏카드 트레이 안으로.

## 5. Key States
- **턴(기본)**: 위 보드 레이아웃. 행동 가능한 ＋/－만 활성, 불가는 흐리게.
- **차례 넘기기(패스스크린)**: "👧 지민 차례!" 큰 카드 — 기기 전달. 보드 가림(공정성).
- **이벤트 공개**: 화면 중앙 **드라마틱 카드 플립** + 황소/곰 연출 + 주가 토큰 이동 애니메이션. (블랙스완은 ❗붉은 번쩍, 인도 성장은 🌱.)
- **결과**: 포디움(🥇🥈🥉) + 콘페티 + 배울점.
- **셋업**: 밝은 보드 톤으로 나라 선택(배지)·인원·난이도.
- **빈/경계**: 카드 없음, 상폐 타일(💀 0원, 회색), 행동 0개(액션바 안내), 마지막 라운드(다음예보 ❓).

## 6. Interaction Model
- 타일 **＋**=사기 1주(초록 팝+동전 튐), **－**=팔기(빨강). 한 번 탭=1행동. 살 수 없으면 ＋ 흐리게.
- 남은 행동 2개를 ●● 점으로 시각화, 쓰면 꺼짐.
- 가격 변동 시 타일 토큰이 **위/아래로 튕기며 색 번쩍**(상승 초록·하락 빨강).
- 큰 사건엔 마스코트 반응: 호황→🐂 돌진, 폭락→🐻. `prefers-reduced-motion`이면 효과 축소.
- 되돌리기는 그대로 유지(아이 실수 안전망).

## 7. Content Requirements
- 톱바: 라운드 `3/12`, 나라칩, 현재 플레이어, 돈(큰 숫자), 랭킹 메달.
- 타일: 아이콘, 회사명(짧게), 가격, 변동(▲▼), 보유수, ＋/－.
- 액션: `남은 행동`, `카드(N)`, `패스 +500`, `되돌리기`, `턴 종료`.
- 마이크로카피 9세 눈높이 유지(현재 톤 계승). 상폐=`💀 0원`, 정보입수 힌트 등 기존 문구 보존.
